# Лабораторная работа № 2: сегментация изображений

Реализована U-Net и два эксперимента: учебный CARLA (23 класса) и CamVid с реальными
дорожными изображениями (11 классов, Void не оценивается). Основная работа —
`CV_L2.ipynb`, краткий отчёт — `REPORT.md`, исходные условия — `ASSIGNMENT.md`.

## Установка и запуск

Проверенная среда: Linux, Python 3.12, TensorFlow CPU 2.18.1. Основные зависимости
перечислены в `requirements.txt`, полный набор проверенных версий — в
`requirements-lock.txt`. Из папки проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-lock.txt
python -m ipykernel install --prefix "$VIRTUAL_ENV" --name cv-lab2 --display-name "Python (CV Lab 2)"
python prepare_data.py
python external_carla.py prepare
```

Открыть notebook в VS Code/Jupyter, выбрать ядро **Python (CV Lab 2)** и выполнить
все ячейки. Для повторного полного запуска сначала перезапустить ядро. Notebook
не пропускает отсутствующие данные: они должны быть скачаны до выполнения.
При `RETRAIN=False` используются сохранённые модели и история, если их параметры
и разбиение совпадают. Повторная оценка и все графики пересчитываются. Если моделей
нет, обучение запускается автоматически. Для нового обучения моделей с 8 фильтрами выставить
`RETRAIN=True` в первой кодовой ячейке. Для моделей с 32 фильтрами
используются отдельные команды ниже.

Автоматический запуск из активированного окружения:

```bash
jupyter-execute CV_L2.ipynb --inplace --timeout 7200
python make_report.py
python verify_results.py
```

Оба эксперимента выполняют 40 эпох с 8 начальными фильтрами, batch size 8 и размером
96×128. Это уменьшенный вариант U-Net для CPU. Исходная ширина 32 доступна через `n_filters=32`; дополнительные полные
обучения и сравнение описаны ниже. Веса двух моделей обучаются независимо с seed=42.

Для просмотра уже полученных результатов повторное обучение не нужно: графики
и таблицы встроены в notebook и сохранены в `results/`. В итоговый архив включены
обученные модели `*.keras`; для предсказаний их можно загрузить через
`tf.keras.models.load_model(path, compile=False)`. Для оценки через `evaluate_model`
сначала вызвать `compile_model(model, ignore_label=...)` из `lab2.py`.

## Данные и воспроизводимость

`prepare_data.py` использует публичный GitHub, фиксированные коммиты и TLS/Git-проверки.
Для скачивания нужен установленный Git. Не нужны Kaggle API, токены или ручной ввод.
С временными Git-копиями нужно иметь
несколько ГБ свободного места.

| Набор | Источник | Разбиение train/val/test |
| --- | --- | --- |
| CARLA | [изображения и маски](https://github.com/Rhythm-Adhikari1/U-Net/tree/072afa362ab567ceb8c151b18b00e05ac632bf26/data) | 848 / 106 / 106 |
| CamVid | [SegNet Tutorial](https://github.com/alexgkendall/SegNet-Tutorial/tree/bb68b64e72cb004b3ed927fee0f5624dd8097498/CamVid) | 367 / 101 / 233 |

Для CARLA используются изображения и маски CameraRGB/CameraMask из источника,
указанного в таблице. Сеть обучается на этих данных с начальной инициализацией весов.

CamVid — опубликованный набор с ручной разметкой. Для него сохранено стандартное
разбиение. Предложение 80/10/10 в условии касается создания собственного набора;
здесь выбран готовый набор. В CARLA выдержано точное 80/10/10, причём кадры с разрывом
ID не более 100 объединены и не разделяются между частями. Это эвристика против
попадания соседних кадров в train и test; метаданных для гарантированного разделения
по поездкам в учебном наборе нет.

После подготовки:

```text
data/
  manifest.json
  carla/
    images/{train,val,test}/
    masks/{train,val,test}/
  camvid/
    images/{train,val,test}/
    masks/{train,val,test}/
```

Манифест хранит версии источников и SHA-256 каждого файла; его копия для отчёта
сохраняется в `results/data_manifest.json`. Повторная команда
`python prepare_data.py` проверяет файлы по манифесту. Изображения и промежуточные
checkpoint-файлы с состоянием оптимизатора исключены из Git; четыре готовые модели
для предсказаний включены в репозиторий. Полные исходные данные скачиваются указанной командой.
Список использованных пар сохраняется отдельно для каждого эксперимента.

CamVid предоставлен авторами SegNet Tutorial для личного и исследовательского
использования: [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/).
Источники: Brostow et al., *Semantic Object Classes in Video: A High-Definition
Ground Truth Database*, Pattern Recognition Letters, 2009;
Kendall, Badrinarayanan, Cipolla, *Bayesian SegNet*, 2015.

## Как оценивается качество

- Изображения нормализуются один раз, маски масштабируются nearest neighbor.
- Для BGRA-масок CARLA берётся красный канал с ID, а не alpha=255.
- В CamVid настоящий Void=11 исключён из loss и метрик; предсказанный Void
  на размеченном пикселе остаётся ошибкой.
- Лучшая эпоха выбирается только по validation loss.
- На тесте считаются pixel accuracy, поклассовые IoU и mean IoU. Классы с нулевым
  объединением исключаются из среднего и отображаются как отсутствующие.
- Baseline всегда предсказывает самый частый **обучающий** класс.
- Сохраняются обычные и худшие тестовые примеры, частые пары ошибок и число
  пикселей каждого класса. Палитра имеет 23 разных цвета и легенду.

В `*_history.csv` Keras записывает индекс эпохи с нуля; в отчёте и `*_run.json`
номер лучшей эпохи начинается с единицы. Каждый вариант обучен с одним seed;
сравнение уменьшенной и полноразмерной сетей приведено ниже. Увеличение разрешения
и повторения с другими seed остаются возможными дальнейшими экспериментами.

`test_lab2.py` проверяет архитектуру, предобработку, IoU по ручному примеру,
обработку Void, уникальность цветов и сохранение модели. `test_real_data.py`
проверяет настоящие данные: состав частей, отсутствие одинаковых изображений
между частями, разделение близких кадров CARLA и чтение реальных масок.
`verify_results.py` дополнительно сверяет 40 эпох каждого эксперимента, выбранную
эпоху, метрики по матрице ошибок и предсказания повторно загруженных моделей;
затем запускает обе группы тестов. Результаты записываются в `results/validation.json`
и `results/tests.txt`.

## Полная сеть и дополнительная проверка

В `results/experiment_32/` сохранены результаты двух дополнительных обучений
с 32 начальными фильтрами, по 40 эпох. Классы взвешены по частотам только в train;
лучшая эпоха выбирается по validation mean IoU. Предыдущие модели на 8 фильтрах
сохранены для сравнения. `*_inference.keras` содержит обученную модель без
состояния оптимизатора, а `*_history.csv` и `*_config.json` — историю и параметры.

Дополнительная контрольная часть содержит 223 кадра из другого публичного набора
CARLA 0.9.5. Она не использовалась при обучении и выборе модели. Метка 0
(`Unlabeled`) исключена из оценки, средний IoU вычисляется по классам 1–12,
присутствующим в разметке. Это иная схема, чем 23 класса исходного набора;
ошибки других предсказанных классов на размеченных пикселях учитываются.
Наборы созданы независимо, но могут содержать общие виртуальные сцены CARLA.

Полное повторение занимает продолжительное время на CPU:

```bash
python external_carla.py prepare
python experiment_32.py carla
python experiment_32.py camvid
python compare_32.py carla
python compare_32.py camvid
python external_carla.py evaluate
python make_report.py
python update_work.py
jupyter-execute CV_L2.ipynb --inplace --timeout 7200
python verify_results.py
```

`external_carla.py prepare` скачивает только 223 пары опубликованной контрольной
части по закреплённому Git-коммиту, проверяет формат масок и совпадение SHA-256
с ранее использованными изображениями. Данные хранятся в `data/carla_external/`;
в архиве есть контрольные суммы, исходные изображения скачиваются отдельно.
Повторный запуск проверки сверяет файлы с сохранённым манифестом.

Тестовые результаты модели с 8 фильтрами учитывались при выборе следующего
эксперимента, поэтому сравнение на том же тесте носит исследовательский характер.
Дополнительные 223 кадра используются после выбора модели по validation. Для
новых научных выводов полезно также повторить обучение с несколькими seed и
изучить реальные изображения других городов.
