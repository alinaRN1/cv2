# Лабораторная работа № 2

## Сегментация изображений с помощью U-Net

В работе построена U-Net для двух наборов данных:

- **CARLA** — дорожные изображения с масками 23 классов.
- **Penn-Fudan** — фотографии людей с масками двух классов: фон и человек.

Основная работа находится в `CV_L2.ipynb`. В ноутбуке показаны загрузка и подготовка данных, построение U-Net, обучение, графики и сравнение настоящих и предсказанных масок. Отчёт находится в `REPORT.md`.

Источники данных: [CARLA](https://github.com/Rhythm-Adhikari1/U-Net/tree/072afa362ab567ceb8c151b18b00e05ac632bf26/data) и [Penn-Fudan](https://github.com/swallan/PennFudanPed/tree/ec1d4583fb436b14e2062587c8b28a5018668a5e). Изображения и маски скачиваются отдельно в папку `data/`.

## Запуск

Нужны Python 3.11 или 3.12, Git и подключение к сети для скачивания наборов данных.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt notebook
python -m ipykernel install --user --name cv-lab2 --display-name "Python (CV Lab 2)"
python prepare_pennfudan.py
jupyter notebook CV_L2.ipynb
```

В Windows для активации используйте `.venv\Scripts\activate`. Скрипт подготовки создаёт папки `images/train`, `images/val`, `images/test` и соответствующие папки внутри `masks/`. Для Penn-Fudan маски преобразуются в классы 0 — фон и 1 — человек.

В `results/` сохранены модели и результаты обучения. При `RETRAIN = False` в ноутбуке используются сохранённые модели; при `True` обучение выполняется заново. Начальное число фильтров — 32, число эпох — 40. Обучение на CPU может занять продолжительное время.

Чтобы обновить отчёт по сохранённым результатам, выполните:

```bash
python make_report.py
```

В конце ноутбука показаны результаты на собственных фотографиях из папки `photos/`. Эталонных масок для этих снимков нет, поэтому метрики для них не вычисляются.
